Glow Up SV is a digital platform designed to connect the Salvadoran community with resources, services, and tools focused on holistic transformation: health, beauty, mental wellness, and lifestyle.

About the Project
This project was born from the need to centralize the wellness offerings in El Salvador, allowing users to find everything from self-care routines to directories of local specialists.

## Tech Stack
Frontend: React.js
Styling: Tailwind CSS (Modern & Responsive Design)
Database: MongoDB

## Installation & Setup
To run this project locally, follow these steps:

### Clone the repository:

---
git clone https://github.com/your-username/glow-up-sv.git
Install dependencies:
---
cd glow-up-sv
npm install
---

Run the development server:

Bash
npm run dev
